# Geometry: A Living Coordinate Universe

*Because math should be touched, not just read.*

✨ **[Play with the Live Demo Here](https://meeseeks-mr.github.io/Geometry/)** ✨

Geometry is a single-file, highly interactive web application designed to bring the Cartesian coordinate system to life. Far too often, dimensions and coordinates are taught on flat, static paper. Here, points, lines, planes, and entire 3D spaces are fluid, explorable, and tactile. 

Built entirely in vanilla HTML/CSS/JS using **Three.js** and **GSAP**, this project is a zero-build love letter to mathematics. 

## What It Does

- **Dimensional Exploration:** Step seamlessly from 0D (a single point) to 1D (the number line), 2D (the coordinate plane), and finally into full 3D space.
- **Live Equation Graphing:** Type in functions like `y = x^2` or `y = sin(x)` and watch them dynamically construct themselves in front of you as thick, glowing curves. 
- **Interactive Modules:** 
  - **Angles & Unit Circle:** Drag a ray to explore acute, obtuse, and reflex angles, while a live unit circle maps out your trigonometric functions.
  - **Pythagoras:** Construct a right triangle from the origin, complete with dynamic area squares that visually prove exactly why $a^2 + b^2 = c^2$.
- **Child & Explorer Modes:** Child mode keeps the math neat by snapping points to integer grids, while Explorer mode unleashes precision, vectors, and complex equations for the mathematically curious.
- **Aesthetic Flexibility:** Wrapped in a sleek glassmorphic UI with dynamic color themes (try *Cosmos*, *Light*, *Dark*, or *Pencil & Paper*) that feels right at home on both desktop and mobile.

## How to Run It

It doesn't get easier than this:
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start dragging the golden point.

There are no bundlers, no build steps, and no `npm install` required. It is the web as it was meant to be.

## Technologies Used

- **Three.js** for the underlying 3D WebGL rendering.
- **GSAP** for the buttery smooth, bouncy animations that make the math feel physically grounded.
- **Math.js** for securely parsing and evaluating the equations you throw at it.
- **Vanilla CSS** with CSS variables for dynamic theming and a frosted-glass UI.
